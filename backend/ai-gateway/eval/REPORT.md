# 妈咪日记 P2 评测报告（DeepSeek deepseek-chat，json_object 降级方案）

日期：2026-10-14（北京时间）。在本机（共享云电脑）跑的，未部署。原始结果：`results-parse-v1.json`、`results-parse-v2.json`。

方案（用户已同意）：`response_format: json_object` + 提示词内附 JSON Schema；网关强制 schema 校验，不合规重试一次，根结构仍不合规报错（502 `schema_invalid`）；个别卡片不合规转 other（status=partial，架构 §5.2）。

## 评测集
- `cases.jsonl`：80 句妈妈口语，覆盖喂奶/睡眠/尿布/情绪/其他、一句多事、汇总、钟点/时段、凌晨补记“昨晚”、辅食月龄、口头语、风险词（4 句）。
- ⚠️ 这些句子是按真实场景**编写**的，不是采集自真实用户；上线内测后应用脱敏的真实输入替换/扩充。
- `summary_cases.json`：10 组统计数据，测小结合规。

小结（10 组）：0 错误，10/10 合规；1 组模型两次都超 50 字，走模板兜底；P50 934 ms / P90 1224 ms。

v1→v2 改动：提示词补尿布 type 规则（“拉了”漏标 poo 3 例）；覆盖检查忽略“嗯…那个”等口头语。
