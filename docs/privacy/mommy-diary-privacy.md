# 隐私政策增补条款草稿：妈咪日记

> 状态：草稿，需要法务审核后并入正式隐私政策，并同步更新应用商店的隐私表单。App 内「设置 → 妈咪日记与隐私」的文案与本稿一致，正式版定稿后两处要一起改。

## 1. 我们处理哪些信息
| 场景 | 信息 | 去向 | 保存 |
|---|---|---|---|
| 按住说话（默认） | 录音 | 只在手机上，由系统自带的语音识别转成文字 | 录音不保存，只保存识别出的文字 |
| 联网语音识别（兜底） | 按住说话期间的录音（16k PCM） | 经哄哄网关实时转发给科大讯飞股份有限公司 | 只在内存中转发，识别完成即删除；不用于训练 |
| AI 整理成卡片 | 识别出的文字、宝宝日龄、当前时间（含时区） | 经哄哄网关发给 DeepSeek（杭州深度求索人工智能基础技术研究有限公司） | 网关不保存文字，日志只记哈希、耗时和状态 |
| 今日小结 | 当天各类记录的次数和时长统计、日龄 | 同上 | 同上 |
| 日记原话、卡片、小结 | — | 只保存在本机 | 用户可在时间线上逐条删除 |
| 喂奶、睡眠、换尿布 | — | 加入家庭后同步给家人（与快捷记录相同） | 同现有条款 |
| 内测统计 | 只有次数（保存、修改、识别失败等），不含任何内容 | 只在本机统计，用户主动复制后才会发给我们 | 本机保留 30 天 |

不会发送：宝宝的小名、性别、生日、baby_id、设备标识。

## 2. 第三方处理方
- **科大讯飞股份有限公司**：负责语音听写（流式版 WebAPI），只在“本机识别不可用，并且用户同意或在设置中开启联网语音识别”时使用。处理目的是把语音转成文字，处理在中国境内进行。
- **杭州深度求索人工智能基础技术研究有限公司（DeepSeek）**：负责把文字整理成卡片、生成今日小结。处理在中国境内进行。

以上两家都不出境（D11）。

## 3. 用户的选择
- 第一次需要联网识别时会弹出告知，用户可以拒绝，拒绝后改用文字输入。
- 在「设置 → 联网语音识别」可以随时开启或关闭。关闭后不再弹窗询问。本机识别不可用时，打字页会显示一行提示，点击可跳到这个开关。
- 不使用妈咪日记，不影响哄哄的其他功能。

## 4. 免责声明（PRD 6.3）
> 妈咪日记仅用于记录宝宝日常情况，不提供医疗诊断或建议。如宝宝出现发热、持续哭闹、精神差等异常情况，请及时咨询专业医生。

出现位置：首次进入时的性别补问页（引导页）、今日小结页、「设置 → 妈咪日记与隐私」和设置页底部（相当于“关于”页）。确认页命中风险词时，显示“如有担心，请及时就医。”
