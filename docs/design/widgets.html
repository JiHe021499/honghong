17 · 桌面小部件 & 下拉快捷开关（Android）

和锁屏快捷记录用同一套逻辑：喂奶 / 睡觉 / 拍嗝 开始 → 计时 → 结束，换尿布一点即记。任何一处操作，App、锁屏通知、小部件、快捷开关同时更新。
小部件和快捷开关不依赖「锁屏快捷记录」开关。

亮起 = 正在计时；点一下 开始 ↔ 结束。换尿布是一次性按钮，点一下记一条。

C · 三个快捷开关：喂奶、睡觉（开关型）、换尿布（一次性）。图标为系统要求的单色剪影（由手绘图标描边生成）。

规则
  • 所有入口共用一套动作：start:feed / end:feed / start:sleep / end:sleep / start:burp / end:burp / diaper；写入方式和 App 内完全一致，加入家庭时标记待同步。
  • 点小部件空白处 / 标题打开 App；按钮在后台执行，不打开 App。
  • 结束只写结束时间，细节在 App 里补（与锁屏一致）。
  • 小部件计时用系统 Chronometer，不需要 App 常驻。
