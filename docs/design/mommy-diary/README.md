# 哄哄 · 妈咪日记（新增功能）设计稿

妈咪日记是加进现有哄哄 App 的一个新功能，不是一个独立的 App。样式直接复用 `../design.html` v1.1 的整套 CSS，写在 `base.css` 里，原样拷贝、没有改动。新增的样式都放在 `md.css`，类名统一用 `md-` 开头，不会覆盖原有类名。图标都用 `app/assets/icons` 里的手绘图标（代码里由 HhIcon 显示）。

## 入口：首页快捷按钮下方的一张卡片
- 底部 4 个标签（首页 / 规律 / 家庭 / 我的）我已经在 `app_router.dart` 的 TabShell 里确认过，保持不变。
- 首页现在从上到下是：头部、状态条、「宝宝在哭」按钮、自动监听开关、快捷按钮、今天的记录。这些都不动，只在快捷按钮和「今天的记录」之间加一张卡片，标题「妈咪日记」，带一个「新」角标。21:00 以后，这张卡片会显示「今日小结已生成」（第 2 屏）。
- 为什么放在这里：妈妈记录的场景就在首页，单手就能点到；放进「规律」标签太深，而且「规律」是看统计的地方，和 PRD 写的 MVP 不做统计图表也对不上。
- 夜间模式下首页本来就会隐藏时间线，这张卡片跟着一起隐藏，夜间首页不变。
- 日记里的页面都是二级页，和「判断结果」页一样：顶部是圆形返回按钮加居中标题，没有底部标签栏。

## 各屏
1–2 首页加了入口卡片；21:00 后入口显示今日小结。
3 第一次进入：直接用 App 里已有的宝宝小名和出生日期（Babies 表），数据库里没有性别字段，所以只补问性别，可以跳过。PRD 里那个单独的引导页就不需要了。
4–5 日记主页：空状态和空闲状态。页面中间是「按住说话」按钮，大小和颜色跟「宝宝在哭」按钮一样；下面是「打字记录」入口和今天的日记。
6–8 录音中（波形、计时、实时转写）→ 上滑取消 → 整理中（显示识别出的原文）。
9 识别失败：底部弹出面板，主按钮是「改用文字输入」。10 文字输入。
11–15 确认页：卡片默认全选，点卡片在原位展开编辑；全部取消勾选后保存按钮变灰；AI 整理失败时原话存成「其他」卡片；出现风险词时只提示「如有担心，请及时就医」。
16–20 保存后弹出提示条，进入当日时间线：顶部是今日小结，下面按时间排序。编辑沿用现有的底部弹出面板（和喂奶结束面板一样），删除前二次确认，也有空状态。
21–23 今日小结：浅色、夜间（沿用现有暗红夜间配色）、当天无记录三种状态。

## 和现有 App 打通（我自己做的决定）
- 时间线里会一起显示首页快捷按钮记下的喂奶、睡觉等记录，标「快捷记录」，避免同一件事记两遍。
- 当日汇总（如「今天共 6 次」）单独标注，不和单次记录重复计数。小结生成后再删除记录，小结不会自动改写。
- 没做：推送、多宝宝、矫正月龄、离线记录（PRD 待定问题）。
- 我新画了一个本子图标作为入口图标，另外画了键盘和编辑小图标，都是直接写在 HTML 里的 SVG，用了相同的深棕描边，还没有导出成 assets 里的图标文件。

文件：`design.html`（加 `?s=<id>` 可以单独看某一屏）、`screens-01…23-*.png`（每屏截图）、`overview.png`（总览）、`compare.png`（现有页面和新页面并排对比）、`gen.py`、`shot.py`。重新生成：`python3 gen.py && python3 shot.py`。
