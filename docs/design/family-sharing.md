# 家庭共享 + 参与改进（第二阶段 App 端设计说明）

## 家庭共享

**模型**：一个家庭 = 一个宝宝。成员都是匿名登录的设备，角色 `owner`（创建者）/ `member`。一台设备同时只在一个家庭。

**页面（底部「家庭」标签）**
1. 未加入：家人头像卡片 + 说明 →「创建家庭」（主按钮）/「输入邀请码加入」（次按钮）。
2. 创建 / 加入底部面板：选「我是 妈妈 / 爸爸 / 老人」（手绘头像 avatar_mom/dad/grandma）；加入时输入 6 位邀请码（大字号、字间距宽）。
3. 已加入：
   - 「邀请家人」卡片：邀请码大字（橘色），「复制」「换一个」。24 小时有效，可多人使用；任何成员都能邀请。
   - 成员列表：头像 + 称呼 +「创建者 / 成员」，自己标「（我）」；创建者可移除别人（手绘 remove 图标，二次确认）。
   - 同步状态行：上次同步时间 /「正在同步…」/ 失败提示 +「立即同步」。
   - 「退出家庭」（次按钮，二次确认；最后一人退出时提示家庭和云端共享记录会被删除）。
4. 未配置云端的构建：显示家人卡片 +「这个版本还没连上云端」。

**共享什么**：宝宝小名/生日、护理记录（喂奶/睡觉/换尿布/拍嗝，含进行中的计时）、哭声判断结果和反馈。**录音不共享**（只在录音那台手机上）。

**规则**
- 加入时：本机已有记录改挂到家庭宝宝名下并上传（合并，不丢数据）。
- 本地优先：所有操作先写本机数据库，联网后自动同步（启动、回到前台、数据变化后 4 秒）。失败按 1/5/30 分钟重试。
- 冲突：最后修改者胜出（按 `updated_at`；同一秒内以后到达服务器的为准）。
- 删除：软删除，删除也会同步给家人。
- 两台手机同时开始同一种计时：保留后开始的那条，先开始的在对方开始时自动结束。
- 退出/被移除：本机记录保留，之后只在本机记录。

## 参与改进（研究数据上传）

- 设置「参与改进（上传匿名数据）」开关，默认关闭；打开时弹出隐私说明，点「同意并开启」才生效，记录同意时间。
- 只上传：有反馈、录音在本机的哭声片段（16kHz 单声道 WAV，裁到最长 30 秒）+ 判断 + 反馈 + 月龄。不传小名、生日。
- 只在 Wi-Fi 下上传；失败下次再试；本地 uuid 作主键，重复上传幂等。
- 研究数据按设备隔离，宝宝 id 按设备派生（uuid v5），与家庭数据无关联。
- 「删除我的数据」：删除云端本设备上传的录音和标注，并关闭开关；本机数据不受影响。
