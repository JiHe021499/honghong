16 · 锁屏快捷记录（Android）

不解锁、不打开 App，在锁屏通知上直接记。喂奶 / 睡觉 / 拍嗝是「开始 → 计时 → 结束」，换尿布一点即记。
通知常驻（可在设置里关闭），锁屏上显示完整内容；计时由系统时钟走，不耗电、不用前台服务。

开启时（Android 13+）先申请通知权限。
中兴等机型需要允许「锁屏通知显示内容」，并把哄哄设为「不限制」电池优化，否则按钮可能延迟。

D · 设置入口（默认关闭，第一次开启时引导）。

交互规则
  • 按钮在锁屏直接生效（不要求解锁）；点通知正文才会解锁并打开 App 首页。
  • 结束 = 写入结束时间，细节（方式、侧别、奶量、备注）之后在 App 里补；App 首页同步显示。
  • App 里开始/结束任何记录，通知同时刷新；锁屏上的操作，App 打开时立即可见。
  • 加入家庭时：锁屏记录同样标记待同步，App 下次在前台/联网时推送给家人。
  • 通知不可滑掉（常驻），要关闭去「我的 → 锁屏快捷记录」。Android 系统通知最多 3 个按钮。
